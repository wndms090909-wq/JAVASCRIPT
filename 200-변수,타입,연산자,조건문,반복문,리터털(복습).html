변수

변할수 있는 데이터를 저장하는 공간

var(vatiable) - 이전버전 : 재선언가능, 재할당
        let - 다시는 선언할 수 없다 : 재선언불가능, 재할당가능(값바꾸기 가능)
        const - 다른 프로그램에서 변할수 없는 데이터를 저장하는 공간

var 변수명1 = 데이터; let 변수명2; 변수명1 = ""(null);

데이터 타입의 종류

        숫자(Number): 1 4.3
        문자(String): "", ""
        Boolean: true, false (1,0) -> 주로 조건문에 사용
        null: 의도적으로 공간을 비운경우
        undefined: 변수 선언을 할때 데이터를 할당하지 않는 경우
        BigInt: 64bit 소수점숫자에 특화

연산자

데이터를 조작하여 처리하는 방식을 뜻함

        산술연산자: +, -, *, /, %
        연결연산자: + -> 템플릿 리터럴 방식: 백틱 `` 요즘사용
        증감연산자: ++, --
        대입연산자: =, +=, -=, *=, /=, %= 오른쪽껄 왼쪽에 넣음 (+= 오른쪽을 왼쪽과 더하여 넣음)
        비교연산자: >, >=, <, <=, ===, !== => true, false
        논리연산자: &&, ||(or), !(현재의 반대상태로 만들어줌)
        삼항조건연산자: 조건문? 조건이 참일때 실행 : 조건이 거짓일때 실행;

조건문

조건이 맞는지 체크하여 조건이 참일때, 조건이 거짓을때 처리할 명령을 주는것

if(if, if~else, if~else if~esle) => 조건이 적을때, 비교연산
switch~case => 조건이 많은경우, 값

        if(조건문){
            조건의 결과가 참일때 실행할 문장
        }

        if(조건문){
            조건이 참일때 실행할 문장;
        }
        else{
            조건이 거짓일때 실행할 문장;
        }

        if(조건문1){
            조건문1일 참일때
        }
        else if(조건문2){
            조건1 거짓, 조건2 참일때 실행
        }
        else if(조건문3){
            조건1 거짓, 조건2 거짓, 조건문3 참
        }
        else{
            모든 조건이 거짓일때 처리할 문장;
        }

        switch(조건에대한값을 저장한 변수){
            case "값1":
                값1일때 처리할 문장;
            break;
            case "값2":
                값2일때 처리할 문장;
            break;
            default:
                위에 값이 없는경우 나머지를 처리할때;
        }

반복문

같은 명령어를 여러번 실행해야될 경우

for => 정해진 횟수만큼 반복, while => 조건이 맞을때까지 반복, do~while => 조건과 상관없이 무조건 한번은 실행 

            for(초기값; 조건식; 증감식){
                반복해서 실행한 문장;
            }
