배열

하나의 이름 안에 여러 형태의 데이터를 저장하는 것.
순서를 가지는 리스트.

정해진 형태없이 다양한 형태를 저장할 수 있음.

숫자, 문자, 객체, 배열, 함수 등

배열과 관련된 명령어

        push : 배열의 마지막에 데이터 추가
                ex) 배열명.push("값");
        pop : 배열의 마지막 데이터 제거
                ex) 배열명.pop();
        unshift : 배열의 앞에 데이터 추가
                ex) 배열명.unshift("값");
        shift: 배열의 앞에 데이터 제거
                ex) 배열명.shift();
