함수

자주 사용되는 명령들을 한곳에 묶어둔것

1. 선언적함수 (명명함수): 이전 => 호이스팅이 됨

2. 함수 표현식 (익명함수): => 호이스팅이 불가

3. 화살표함수 es6부터 도입, 함수를 간결하게 사용하려고 도입 => this 사용불가

호이스팅: 선언전에 호출하는 것

        1. 선언적함수
        function 함수이름(매개변수, 매개변수2, 매개변수3){
            return 되돌려줄 값
            실행할 명령어들;
        }

        2. 함수 표현식
        let 함수이름 = function(매개변수){
            실행할 명령어들;
        }

        3. 화살표함수
        let 함수이름 = (매개변수) => {
            실행할 명령어들;
        }
